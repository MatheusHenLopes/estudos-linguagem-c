# Estudos em C

Repositório destinado ao registro dos meus estudos e exercícios desenvolvidos em linguagem C durante o curso Técnico em Informática.

O objetivo é consolidar os fundamentos da linguagem e da lógica de programação por meio da resolução prática de exercícios, mantendo um histórico da minha evolução ao longo dos estudos.

## Conteúdos

- Entrada e saída de dados
- Variáveis e tipos de dados
- Operadores
- Estruturas condicionais
- Estruturas de repetição
- Vetores
- Funções

O repositório será atualizado progressivamente conforme o avanço dos estudos.
